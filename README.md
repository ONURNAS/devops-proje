# DevOps Pipeline Projesi

Basit bir Python uygulamasını otomatik olarak paketleyen küçük bir DevOps çalışması.

## Ne yapıyor?
- Python ile yazılmış basit bir uygulama
- Docker ile paketlenmiş (her yerde aynı şekilde çalışır)
- GitHub Actions ile her kod değişikliğinde paket otomatik yeniden oluşturuluyor

## Kullanılan araçlar
Linux (Ubuntu), Git/GitHub, Docker, GitHub Actions

## Nasıl çalıştım?
Uygulamayı Ubuntu sanal makinesinde SSH ile bağlanarak geliştirdim ve Docker ile test ettim.

## Neden yaptım?
DevOps'un temel mantığını (kodu yaz, paketle, otomatik kontrol et) uygulamalı öğrenmek için.
